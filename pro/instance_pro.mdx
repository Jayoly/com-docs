容器实例Pro是针对容器实例的不足而开发的与容器实例互补的产品，主要特性和优劣势对比如下：

| 对比项目 | 容器实例 | 容器实例Pro |
| --- | --- | --- |
| 是否支持API | 无 | 有 |
| 使用体验 | 系统盘和数据盘均使用本地磁盘，和物理机绑定，机器无 GPU 时需等待或克隆 | 存算分离，和物理机非绑定关系，只要总GPU库存充足随时开机 |
| 磁盘容量和计费 | 默认系统盘 30GB + 数据盘 50GB，默认容量免费，数据盘可付费扩容，系统盘不支持扩容 | 系统盘 30GB，最大可扩容至 500GB，需付费；无数据盘（可能会支持） |
| 磁盘 IO | 本地磁盘，多数为NVMe磁盘，IO 性能高 | 系统盘为网络存储。磁盘 IO 相对容器实例的本地NVMe磁盘更低，但相对文件存储更高 |
| 实例释放周期 | 连续关机 15 天后释放 | 连续关机 60 天后释放 |
| 存储挂载 | 支持文件存储、高速文件存储挂载 | 支持文件存储挂载 |
| 优势 | 1. 磁盘IO性能最佳且价格便宜，适合IO要求高的训练任务 | 1. 和物理机非绑定关系，GPU库存充足即可开机，无需等待或迁移实例<br />2. 有API支持，可自动化创建、管理、销毁实例 |
| 劣势 | 1. 当前物理机GPU不足需要等待或迁移实例<br />2. 不支持API创建管理实例 | 1. 磁盘IO性能逊于本地NVMe磁盘<br />2. 付费磁盘的价格要高于容器实例 |
